# Launch the twbparser Shiny app

Opens an interactive workbook inspector for `.twb` and `.twbx` files.

## Usage

``` r
run_twbparser_app(...)
```

## Arguments

- ...:

  Additional arguments passed to
  [`shiny::runApp()`](https://rdrr.io/pkg/shiny/man/runApp.html).

## Value

The value returned by
[`shiny::runApp()`](https://rdrr.io/pkg/shiny/man/runApp.html).
