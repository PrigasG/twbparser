# Summary of all pages (counts and quick descriptors).

Summary of all pages (counts and quick descriptors).

## Usage

``` r
twb_pages_summary(x)
```

## Arguments

- x:

  TwbParser or xml2 document.

## Value

Tibble with columns including page_type, name, and count columns such as
n_zones, n_worksheets, n_filters, n_legends, n_parameter_controls,
n_story_points, and mark_types for worksheets.
